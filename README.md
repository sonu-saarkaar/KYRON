## 🎯 Quick Start

### Option 1: Run Everything (Easiest)

```powershell
.\RUN_PROJECT.ps1
```

### Option 2: Run Separately

**Backend:**
```powershell
cd backend
.\START.ps1
```

**Frontend:**
```powershell
cd frontend-react
npm install
npm run dev
```
